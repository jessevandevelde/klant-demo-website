# Noordlicht Fietstechniek

Dit is een demo-website voor het fictieve bedrijf Noordlicht Fietstechniek. De site bevat een homepage, een pagina over het bedrijf en een contactpagina.

## Website openen

Open `index.html` in een webbrowser. Gebruik daarna de navigatie om de andere pagina's te bekijken.

## Bestanden

- `index.html` - homepage
- `about.html` - informatie over het bedrijf
- `contact.html` - contactgegevens en openingstijden
- `style.css` - gezamenlijke vormgeving
